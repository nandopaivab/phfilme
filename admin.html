Integração do Banco de Dados no Firebase

Siga os passos rápidos abaixo para ativar o banco de dados online do projeto.

Atualmente, o projeto está rodando em Modo de Demonstração (Demo Mode), salvando tudo no navegador local. Para habilitar o banco em nuvem:

  1. Acesse o Firebase Console e crie um projeto chamado PHFILME.
  2. No painel do projeto, clique no ícone de engrenagem no topo esquerdo e depois em Configurações do Projeto. No rodapé, crie um Aplicativo Web (</>).
  3. Copie o objeto de configurações fornecido (contendo apiKey, authDomain, etc.) e substitua-o no arquivo js/firebase-config.js.
  4. No menu lateral esquerdo do Firebase, vá em Build -> Authentication, ative e selecione o método de login E-mail/Senha. Crie a conta do administrador desejada.
  5. Vá em Build -> Firestore Database, clique em Criar Banco de Dados, selecione a região mais próxima e inicie em "Modo de Produção".
  6. Nas regras do Firestore, vá na aba Regras (Rules) e insira o código abaixo para garantir segurança absoluta dos leads cadastrados:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Permite que qualquer um envie proposta no formulário de leads
    match /leads/{document} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }
    // Permite leitura pública do portfólio, pacotes e agenda, mas apenas admins gravam
    match /portfolio/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /plans/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /config/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    // Permite gerenciamento de usuários autenticados
    match /users/{document} {
      allow read, write: if request.auth != null;
    }
  }
}
